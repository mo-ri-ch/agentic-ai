Words that do things

I can only write text. So what if I write down what I want done… and someone else does it?

That someone is a small program. It reads everything the LLM writes.

You are the program. Click the line you must act on.

Two lines are just words. One asks for something to be done.

A line starting with ACT: asks for something to be done. The program does it, here with a calculator. Anything the program can do when asked is a tool.
the LLM writes → the program does

🤔 How does the LLM know to write ACT:?
Someone tells it, in text placed before your question: “To use the calculator, write ACT: calculator(…)”. The LLM guesses words that fit, and today's LLMs are also trained to follow such instructions. Coming in Lesson 2.

result → LOOK: line → the LLM reads it

One tool was enough here. What if a task needs more?

The loop

Some tasks need several steps. So the program keeps going round: the LLM thinks, asks to act, the program writes what to look at. One trip round the loop is one round, and uses one tool.

Step through. Watch the loop go round twice.

The loop stops when the LLM writes ANSWER:. The LLM writes once in each round (its THINK: and ACT: lines together), then once more for the answer. Here: 2 rounds, so the LLM wrote 2 + 1 = 3 times.
times the LLM writes = rounds + 1

In case it never answers, the program also stops after a set number of rounds, called the step limit.
