Tools are functions

First, my tools.

In code, a tool is a Python function: text goes in, text comes out.

def weather(city):
    today = {"kochi": "29°C, sunny", "delhi": "18°C, foggy", "pune": "24°C, light rain"}
    return today.get(city.lower(), f"Error: no city called {city}")

today is a dictionary: city → weather. today.get(city, …) looks the city up. If it isn't there, you get the error instead.

def calculator(math):
    for ch in math:
        if ch not in "0123456789+-*/(). ":
            return "Error: the calculator only takes numbers and + - * / ( )"
    if "**" in math:   # ** is power: 9 ** 999999 would never finish

    except Exception:

It checks each character first. try catches math that goes wrong, like 2 / 0, and sends back an error.

The ACT: line only gives the tool's name, as text. So the program keeps every tool in another dictionary, name → function, and finds the tool by its name:

TOOLS = {"calculator": calculator, "weather": weather}

TOOLS["weather"]            # → the weather function
TOOLS["weather"]("Kochi")   # → same as weather("Kochi") → "29°C, sunny"

TOOLS[name](input) = find the tool, then run it.

The program needs that name. How does it get it out of the LLM's reply?

Find the ACT: line

Edit the reply, or pick one. See what the program finds.

One line of Python finds it. It looks for the pattern ACT: name(input):
act = re.search(r"ACT: (\w+)\((.*)\)", reply)
For ACT: weather("Kochi"), act.group(1) is weather and act.group(2) is "Kochi". No match? Then act is None.

🤔 What do the symbols in the pattern mean?
  • Each pair of round brackets ( ) is a blank to fill in. act.group(1) gives blank ①, act.group(2) blank ②.
  • (\w+): blank ①, one or more letters, digits or _ : the tool's name.
  • \( and \): real brackets.
  • (.*): blank ②, anything in between: the input.
  • r"…": the r keeps every \ exactly as written, so the pattern gets it.

The loop in code

Press a part of the loop. See which lines do it.

Each pass through the for loop is one round. range(step_limit) runs it at most step_limit times: 5, unless you pass another number. return ends it early: an answer in round 2 means only 2 rounds run.
The loop ends at ANSWER: (return), or after step_limit rounds.

🤔 What's in INSTRUCTIONS? The tool list and the rules, at the top of the text every round: 
You are an agent. TOOLS you can use:
calculator(math) - works out math exactly. Give it the math, like 12 * 7.
weather(city) - the weather right now in a city. Give it the city name.
To use a tool, write one line: ACT: tool(input)
Then stop. The result will come back on a LOOK: line.
When you know the answer, write: ANSWER: your answer

🤔 Which real LLM do we use?
A small, free model, Qwen2.5 1.5B, that runs inside Colab. No account or key needed. Small models make more mistakes than big ones, so expect the odd error. Errors go back on LOOK: lines, so it can often fix them.

The code

Guess what each print shows. Then press ▶ Run.

import re

# Tools: plain Python functions. Text in, text out.
def calculator(math):
    for ch in math:
        if ch not in "0123456789+-*/(). ":
            return "Error: the calculator only takes numbers and + - * / ( )"
    if "**" in math:   # ** is power: 9 ** 999999 would never finish
        return "Error: the calculator only takes numbers and + - * / ( )"
    try:
        return str(eval(math))
    except Exception:
        return "Error: that math doesn't work out"

def weather(city):
    today = {"kochi": "29°C, sunny", "delhi": "18°C, foggy", "pune": "24°C, light rain"}
    return today.get(city.lower(), f"Error: no city called {city}")

TOOLS = {"calculator": calculator, "weather": weather}
print(TOOLS["weather"]("Kochi"))

# The tool list, at the top of the text, every time
# (""" … """ is a string over several lines)
INSTRUCTIONS = """You are an agent. TOOLS you can use:
calculator(math) - works out math exactly. Give it the math, like 12 * 7.
weather(city) - the weather right now in a city. Give it the city name.
To use a tool, write one line: ACT: tool(input)
Then stop. The result will come back on a LOOK: line.
When you know the answer, write: ANSWER: your answer"""

# A fake LLM: it just hands back the next reply from a list
fake_replies = [
    "THINK: Exact math. I'll use the calculator.\nACT: calculator(4817 * 263)",
    "ANSWER: 4,817 × 263 = 1,266,871.",
]
def fake_llm(text):
    return fake_replies.pop(0)

# The loop: think, act, look, until ANSWER: or the step limit
def run_agent(question, llm, step_limit=5):
    text = INSTRUCTIONS + "\n\nQuestion: " + question + "\n"
    for step in range(step_limit):
        reply = llm(text)
        print(reply)
        text += reply + "\n"
        if "ANSWER:" in reply:
            return reply.split("ANSWER:")[1].strip()
        act = re.search(r"ACT: (\w+)\((.*)\)", reply)
        if act is None:
            look = "Error: write ACT: tool(input) or ANSWER: your answer"
        elif act.group(1) not in TOOLS:
            look = f"Error: no tool called {act.group(1)}"
        else:
            look = TOOLS[act.group(1)](act.group(2).strip('"'))
        print("LOOK:", look)
        text += "LOOK: " + look + "\n"
    return "Stopped: the step limit was reached."

print(run_agent("What is 4,817 × 263?", fake_llm))
