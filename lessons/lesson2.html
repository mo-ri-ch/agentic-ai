Tools

Tell it what it can use

I'd love to use a calculator. But how would I know there is one?

Turn the tool list off and on. Then let the LLM write.

The program puts a tool list at the top of the text, every time, before your question. The LLM reads it like everything else, so it knows which tools exist and how to ask for them.

🤔 Who writes the tool list?
The person who builds the agent. It goes in the instructions: text the LLM sees before every question, often called the system prompt. Real tool lists are often written in JSON, a stricter format, but they say the same things.

The list has several tools. How does the LLM pick one?

Which tool?

The LLM reads each tool's description, then writes the ACT: line that fits the question.

You are the LLM. Pick the tool for each question.

Good descriptions

Same question, two tool lists. Switch between them.

The LLM can only go by the words in the list. A good description says three things:
name + what it does + what to give it
weather + “the weather right now in a city” + “the city name”.

Even a good tool can fail. Then what?

When a tool fails

Step through. Something goes wrong in round 1.

The program doesn't stop when a tool fails. It writes the error on the LOOK: line, like any result. The LLM reads it, fixes its mistake and tries again.
errors go back on a LOOK: line too
The retry costs a round: 2 rounds here, so 2 + 1 = 3 LLM writes.

Tools that change things

Sort each tool. Then press Check.

A tool that only looks changes nothing, so trying again is safe. A tool that changes something, like sending an email, can't always be undone. An agent needs more care with those: coming in Lesson 7.
