Memory

The text is its memory

How do I remember what I found two rounds ago? Let's see.

Tap a line to hide it from the LLM. See what it writes next.

The LLM keeps nothing in its head between writes. Each time, it reads the text from the top. What's in the text is all it knows.
memory during a task = the text
Hide the LOOK: line, and it asks for the weather again.

The text grows every round. Can it grow forever?

The text has a limit

Add rounds. Then switch how the program makes room.
Rounds: 3
Words

An LLM can only read so much text at once: its context window. Here it's 300 words. 60 (tool list) + 10 (question) + 4 rounds × 50 = 270 fits. A 5th round makes 320: something must go. Keep the start, and drop the oldest rounds.
text = start + rounds × words per round

🤔 How big are real context windows?
They're counted in tokens (pieces of words), not words. The small model in our Colab notebooks reads up to 32,768 tokens. Big models read hundreds of thousands. Long tasks can still fill them.

Summaries save space

Three rounds of shopping prices. Squeeze them into one line.
Words

A summary keeps the facts and drops the rest. The program asks the LLM to write it, one extra write, then swaps it in for the old rounds. The LLM's next step is the same, with far fewer words.
summary = the facts, in fewer words

That's memory during one task. What about the next task?

Notes for next time

Yesterday the agent saved a note. Today's task starts a new text. Switch the notes off and on.
Yesterday: “I'm vegetarian. Please remember that.” → ACT: save_note(The person is vegetarian.)

A new task starts a new text, so the old one is gone. Notes are saved outside the text, in a list. The program puts them at the top of every new text.
notes = memory between tasks
The note “The person is vegetarian.” → paneer tikka, not butter chicken.

🤔 What if the program stops?
A list is gone when the program ends. So a real agent saves its notes to a file (or a database), and loads them back when it starts.
🤔 What if there are hundreds of notes?
They won't all fit in the context window. So the program searches the notes and puts in only the ones that match the question. This is often called retrieval, or RAG.

Here's notes memory in Python.

The code

The notes list lives outside run_agent, so it survives between tasks. Guess what each print shows. Then press ▶ Run.

import re

# Long-term memory: notes kept outside the text, in a list
notes = []

def save_note(note):
    notes.append(note)
    return "Saved."

TOOLS = {"save_note": save_note}

# The instructions now end with every note saved so far
def instructions():
    rules = """You are an agent. TOOLS you can use:
save_note(note) - remember something for next time. Give it the note.
To use a tool, write one line: ACT: tool(input)
When you know the answer, write: ANSWER: your answer
NOTES from earlier tasks:"""
    for note in notes:
        rules += "\n- " + note
    return rules

# A fake LLM that reads the text, so you can see the notes matter
def fake_llm(text):
    if "Question: I'm vegetarian" in text:
        if "LOOK:" not in text:
            return "THINK: That's worth remembering.\nACT: save_note(The person is vegetarian.)"
        return "ANSWER: Got it. I'll remember that."
    if "- The person is vegetarian." in text:
        return "ANSWER: How about paneer tikka? It's vegetarian, like you."
    return "ANSWER: How about butter chicken?"

# The same loop as Lesson 3. It also shows how long the text has grown.
def run_agent(question, llm, step_limit=5):
    text = instructions() + "\n\nQuestion: " + question + "\n"
    for step in range(step_limit):
        reply = llm(text)
        print(reply)
        text += reply + "\n"
        print("(the text is now", len(text.split()), "words)")
        if "ANSWER:" in reply:
            return reply.split("ANSWER:")[1].strip()
        act = re.search(r"ACT: (\w+)\((.*)\)", reply)
        if act is None:
            look = "Error: write ACT: tool(input) or ANSWER: your answer"
        elif act.group(1) not in TOOLS:
            look = f"Error: no tool called {act.group(1)}"
        else:
            look = TOOLS[act.group(1)](act.group(2).strip('"'))
        print("LOOK:", look)
        text += "LOOK: " + look + "\n"
    return "Stopped: the step limit was reached."

# Task 1, before any notes
print(run_agent("Suggest a dinner for me.", fake_llm))
# Task 2: tell it something worth remembering
print(run_agent("I'm vegetarian. Please remember that.", fake_llm))
print(notes)
# Task 3: a brand new text, but the note is at the top
print(run_agent("Suggest a dinner for me.", fake_llm))
